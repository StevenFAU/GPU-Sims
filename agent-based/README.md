# Agent-based emergence

Simulations where macro-scale structure emerges from many small agents following simple local rules. Performance hinges on parallel agent updates and efficient spatial queries.

## Sims in this category

- [`physarum/`](physarum/) — 10M agents, 3 species with mutual repulsion, territorial boundary formation. 2D by design. **Stack B (WebGPU).**
- [`boids-3d/`](boids-3d/) — 100k boids + 1k predators in a 3D volume; fish-school evasive emergence. **Stack B (WebGPU).**

For category rationale see [`../docs/overarching-spec.md`](../docs/overarching-spec.md) §5–§6.
