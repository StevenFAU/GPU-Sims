GPU-Sims — Gallery

A portfolio of GPU-accelerated physics and emergence simulations.

Source: github.com/StevenFAU/GPU-Sims

Strange Attractors

2M particles integrating Lorenz / Aizawa / Thomas ODEs. RK4 integration, HDR additive accumulation. Closed-form / Stack B.

Mandelbulb Explorer

Distance-estimator raymarcher with soft shadows and orbit-trap coloring. First Stack A → B port in the repo. Closed-form / Stack B.

Reaction-Diffusion 2D

Gray-Scott pattern explorer with six Pearson 1993 named presets and mouse-paint brush. Compute ping-pong on persistent 2D state. Continuous CA / Stack B (Shadertoy → WebGPU port).

Physarum

Multi-species slime-mold transport networks. ~10M agents, three-species mutual repulsion, persistent food-source pins. First atomic-buffer compute consumer in the repo. Agent-based / Stack B (no Shadertoy counterpart).

Hello (common-web demo)

Reference application exercising the common-web Stack B infrastructure: compute, render, hot-reload, capture, lil-gui.
